# Конструктор упражнений по русскому бильярду

Одностраничный редактор схем упражнений на 12-футовом столе. Тренер расставляет
шары, а на выходе получает PNG, который можно отправить ученику. Бэкенда нет,
данные никуда не уходят.

## Этап 1 (текущий)

- Стол 3550 × 1775 мм: сукно, борта, шесть луз с реальными створами (72 и 82 мм),
  разметка по четвертям и продольная линия, отметки.
- Белые шары и биток: добавление кликом, перетаскивание мышью и пальцем,
  точный сдвиг стрелками (5 мм, с Shift — 1 мм).
- Магнит к разметке и лузам, запрет наложения шаров — оба отключаются.
- «Расставить пирамиду»: 15 шаров от задней отметки плюс биток в доме.
- Undo/redo (Ctrl+Z / Ctrl+Shift+Z), очистка стола, поворот стола.
- Экспорт PNG в 1x / 2x / 3x.

Этапы 2–4 (стрелки, зоны, виджет удара, библиотека) добавляются новыми ветками
в `Item` и в `ItemView` — см. «Архитектура».

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build -> dist/
npm run preview
```

Деплой: Netlify, статика из `dist`, конфиг в `netlify.toml` (Node 20,
SPA-редирект на `index.html`).

## Архитектура

Ключевое правило: **внутренние координаты — миллиметры стола**, начало координат
в левом верхнем углу игрового поля. Пиксели появляются ровно в одном месте — в
трансформации слоя Konva. Поэтому схема одинаково выглядит на телефоне и в
экспорте на 3x, а сцену можно перенести между экранами без пересчёта.

```
src/
  model/       чистые данные и геометрия, без React и без Konva
    types.ts     Scene, Item (union на все этапы), TableConfig
    table.ts     buildGeometry(): лузы, губки бортов, разметка, отметки
    theme.ts     палитра; вся графика рисуется кодом, ни одного внешнего ресурса
  state/
    store.ts     zustand + immer, история из снапшотов сцены (лимит 50)
  lib/
    place.ts     магнит, расталкивание шаров, пирамида, id
    exportPng.ts PNG: Blob-путь, ограничения канваса в Safari, имя файла
  render/
    layout.ts    единственный перевод мм -> px, поворот стола, обратное
                 преобразование указателя
    TableView    стол целиком, чистая функция от геометрии
    BallShape    один шар
    ItemView     диспетчер по типу объекта — точка расширения для этапов 2–4
    SceneStage   Stage, ввод, горячие клавиши
  ui/
    Toolbar      панель инструментов
    styles.css   вся вёрстка приложения
```

Внешние ресурсы не подключаются намеренно: шрифт с CDN или картинка с чужого
домена «пачкают» канвас, и `stage.toDataURL` перестаёт работать — то есть
ломается главная функция приложения.
